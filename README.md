  • Descripción del      proyecto •


Este programa permite generar nombres de usuario para estudiantes y verificar si sus contraseñas cumplen con las condiciones establecidas.

    .Entrada

Nombre, apellido y contraseña del estudiante.


  .Proceso

Se genera el usuario utilizando la inicial del nombre y el apellido. Luego se comprueba que la contraseña tenga al menos 8 caracteres y no contenga el nombre de usuario.

     .Salida

Se muestra el usuario generado y si la contraseña es válida.

Ejemplo:

- Usuario: lmora
- Clave válida: True

• Tecnologías utilizadas•

- Lenguaje: C#.
- Entorno de desarrollo: Visual Studio comunity.

   .Conclusión

Con esta actividad practicamos el manejo de cadenas de texto, las funciones y la validación de datos mediante C#.
